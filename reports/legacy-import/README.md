# Rapoarte locale de import

Scriptul `pnpm legacy:import` scrie aici raportul de execuție, rejects JSONL, carantina CSV și sugestiile de redirect. Artefactele sunt ignorate de Git deoarece pot conține nume de recenzori, URL-uri de proveniență și informații operaționale despre exportul legacy.

Nu copia rapoartele în `public/` și nu activa sugestiile de redirect înainte de revizuirea lor individuală.
